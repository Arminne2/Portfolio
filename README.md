# Portfolio

Huitième et dernier projet du parcours "développeur web" chez OpenClassrooms. Ce projet vise à présenter le travail accompli durant la formation à travers la création de mon portfolio.

## Technologies utilisées 

React
React Router
CSS

## Installation 

Clônez ce repository GitHub
Accédez au répertoire du projet
Rentre les commandes suivantes :

```
npm install

npm start

```
